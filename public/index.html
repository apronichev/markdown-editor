          How your files are handled

          • Editing happens in your browser. Nothing is written to GitHub until you press Commit & push.
          • Each save is a normal commit on the branch selected in the sidebar.
          • If someone else changed the file first, the push is refused instead of overwriting their work.
          • Drag a document onto a folder in the sidebar to move it; both the move and the delete happen in one commit.
          • Your GitHub token is held in an encrypted, HTTP-only cookie and is never exposed to page scripts.
