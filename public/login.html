Sign in with GitHub to browse, organize and edit the Markdown files in your repositories — including private ones — and push your changes back as ordinary commits.

Continue with GitHub

The app requests the repo scope, which is the narrowest GitHub scope that can both read and push to private repositories. Your access token is sealed in an encrypted, HTTP-only cookie — it is never stored on a server and never exposed to page scripts.
